# triage-demo

A small, deliberately unglamorous order-processing service. It exists as a
live target repo for [ci-triage-agent](https://github.com/tiagosantosmr/ci-triage-agent):
a real Python package, with real git history and a real CI workflow, that
the agent triages and patches CI failures against.

Nothing here is meant to be impressive on its own. See the agent repo for
the interesting part.
